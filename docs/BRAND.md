# Compasless interface identity

Reference: COMPASLESS_Brand_Guidelines.pdf supplied by the owner, version 2.1.

- Signal red: #C8201E, used for primary actions and focus indicators.
- White: #FFFFFF, the preferred interface ground.
- Black: #16171A, used for text and strong states; neutral shades are black tints.
- Readable sans-serif hierarchy, monospaced technical identifiers, ordered grids.
- Status always has a text label; color alone never conveys device state.

The company mark is the supplied Profile Pic.png, copied unchanged into
src/assets/compasless-mark.png. It retains its proportions and clear space. The
guide notes that supplied raster red differs from the working color specification;
the artwork is preserved while interface actions use the specified signal red.
The interface wordmark uses the exact spelling COMPASLESS.

The brand artwork remains Compasless property; the application's AGPL software
license does not grant rights to present another product as Compasless.
